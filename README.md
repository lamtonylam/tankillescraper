# Tankille.fi Scraper and GraphQL API

### Quickstart

```bash
npm i
npm run dev
```

Or with Docker:

```bash
docker-compose up
```

Go to
<https://localhost:4000/graphql> to access the GraphQL playground.

### Dev scripts

Linting:
```bash
npm run lint
```

Fixing linting errors:
```bash
npm run lint:fix
```

Build 
```bash
npm run build
```
